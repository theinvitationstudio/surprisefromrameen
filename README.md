# Birthday surprise

Open `index.html` to see it. To customise, edit `config.js` (all the text) and put photos in `images/`.

## Put it online with your own link (GitHub Pages)
1. Create a new public repository on GitHub. Pick a plain name, because it appears in the link.
2. Upload `index.html`, `config.js`, `README.md` and the `images` folder (Add file > Upload files).
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After a minute your link is `https://YOURNAME.github.io/REPOSITORY/`.

## Change things later
- Text: open `config.js` on GitHub, click the pencil icon, edit, then "Commit changes". The site updates in 1 to 2 minutes.
- Photo: upload it into the `images` folder (Add file > Upload files), then set `photo: "images/yourphoto.jpg"` in `config.js`.
- Tip: after an update, open the link in a private tab or refresh twice so you do not see the old version.

## Notes
- The passcode is a fun lock. Anyone who views the page source can read it.
- Use a custom domain (Settings > Pages > Custom domain) if you want a link with no github.io in it.
